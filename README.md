# PortHub v1.0.1 — глобальный поиск GitHub

Настольный каталог публичных GitHub-проектов на Avalonia 12 / .NET 10 с сервером ASP.NET Core.

## Основные возможности

- При открытии показываются популярные публичные репозитории со **всего GitHub**.
- Введи запрос в строку поиска на главной или в библиотеке: через 650 мс выполняется **настоящий глобальный поиск GitHub**.
- Переключение страниц в библиотеке; 30 записей на страницу. GitHub Search API позволяет получить не более 1000 результатов одного запроса.
- Релизы и файлы загружаются только **по нажатию** на проект, чтобы не расходовать лимит API на тысячи ненужных запросов.
- Добавленные вручную репозитории сохраняются локально и остаются доступны отдельно от результатов поиска.
- Каталог получает данные через PortHub.Api на Render; сервер хранит PAT в `GITHUB_TOKEN`, кеширует ответы и возвращает только публичные репозитории. Ни один токен не помещается в Windows-клиент.
- Загрузки сохраняются в `%APPDATA%\porthub\apps` (или в выбранную пользователем папку).

## Что каталог НЕ делает

GitHub хранит исходные коды, а не только готовые приложения. Поэтому наличие проекта в результатах поиска **не означает**, что его можно установить. Кнопка `Проверить релиз` запрашивает последний стабильный GitHub Release. Если скачиваемых файлов нет, открывается страница проекта. Автоматическая установка или запуск архивов не предусмотрены.

## Порядок установки обновления

1. Закоммить новые файлы **клиента и API-сервера** в `verge-src/PortHub`.
2. Render должен пересобрать `PortHub.Api` из `src/PortHub.Api/Dockerfile` (контекст сборки — корень репозитория).
3. Проверь публичный маршрут `https://porthub-api.onrender.com/api/search/repositories?page=1` — должен возвращать JSON-результаты.
4. Для сборки Windows запусти `PUBLISH-WIN-X64.cmd` после обновления репозитория или открой `PortHub.sln`.
5. `publish/PortHub-win-x64/PortHub.exe` и `porthub.config.json` нужно распространять вместе. Конфиг содержит только публичный URL сервера, не PAT.

### Серверные лимиты

Глобальный поиск GitHub Search API ограничен (авторизованный поиск обычно до 30 запросов/мин на токен). PortHub кеширует результаты на сервере 5 минут, выполняет поиск с задержкой ввода, а сервер ограничивает входящие запросы. Отдельный Search-запрос показывает не более первых 1000 результатов; это свойство GitHub, не ограничение числа проиндексированных репозиториев.

### Проверка

XAML, имена/обработчики элементов, структура файлов и ZIP проверены статически. В среде подготовки нет .NET SDK, поэтому полную компиляцию и запуск Windows UI нужно проверить на своём компьютере до публикации релиза.
